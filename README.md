# Square Image — Interior & Exterior

A modern business website created for Square Image, an interior and exterior design business.

## 🌐 Live Website

https://www.squareimage.in/

## 📌 About the Project

Square Image is a responsive business website designed to showcase interior and exterior design services, projects, and completed work.

The website provides visitors with information about the business, services, gallery, and contact options.

## ✨ Features

- Responsive website design
- Modern and clean user interface
- Interior and exterior project showcase
- Image gallery
- About section
- Services section
- Contact section
- WhatsApp contact integration
- Mobile-friendly layout
- Custom domain with HTTPS

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
